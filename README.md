# Extrapolation-aware benchmark for ML prediction of MPEA hardness and yield strength

Code and data accompanying the manuscript *"Extrapolation-aware evaluation and calibrated uncertainty for machine-learning
models of high-entropy alloy hardness and yield strength"* (R. Amin, M.M.R. Rana, S. Akter).

## Data
| File | Content |
|---|---|
| `data/hv_records.csv` | 501 room-temperature Vickers hardness records (MPEA database, Borg et al. 2020) |
| `data/ys_records.csv` | 1,067 yield-strength records with test type and temperature |
| `data/ext_ge_records.csv` | 86 external refractory alloys (Detor et al. 2022; figshare 10.6084/m9.figshare.17032760, CC BY 4.0) |
| `data/composition_features.csv` | FRAC / PHYS (WenAlloys) / MAG (Magpie) features for all unique compositions |
| `data/splits.json` | frozen outer splits (test record IDs) for all protocols |

Source data: `CitrineInformatics/MPEA_dataset` (commit d31e2510) and the GE figshare file (MD5 2a829ae75f620735b874b73fe69bf4d5).

## Pipeline
1. `curate.py` – parse and filter the MPEA and GE records.
2. `featurize.py` – matminer/pymatgen composition features.
3. `export_splits.py` – freeze the six evaluation protocols (`common.make_splits`).
4. `bench.py <HV|YS> [models] [protocols]` – first run: nested tuning (random, composition- or system-grouped inner
   folds), CV+ intervals, AD distances. P1–P3 results of this run are used in the paper; for P4–P6 it serves as the
   system-grouped tuning sensitivity analysis (Table S16). `external.py` – the same for the GE set.
5. `normalized_cp.py` – winsorized AD distance and distance-normalized CV+ for XGBoost.
6. Kaggle notebooks (`kaggle/*.ipynb`): TabPFN v2 on GPU; yield-strength GPR, RF, MLP; feature ablation and
   de-duplication sensitivity (`ablation.py`, `dedup_sensitivity.py`).
7. `analysis.py`, `screening.py`, `ad_variants.py`, `shap_analysis.py`, `noise_floor.py` – tables and statistics.
8. `figures.py`, `fig1.py`, `graphical_abstract.py` – figures.

All random seeds are fixed. Hyper-parameter search spaces are in `models.py`.
Environment: Python 3.13, scikit-learn 1.9.1, XGBoost 3.4.1, matminer 0.10.1, shap 0.54, tabpfn 9.2.0.

Explanatory figures (added): `fig_workflow.py` (Fig. 1, study design), `mechanism_stats.py` + `fig_mechanism.py`
(Fig. 3, nearest-training-alloy composition distances and random-split errors for seen/unseen compositions) and
`fig_calibration_mechanism.py` (Fig. 8, interval half-width needed for 90% coverage versus naive/matched/normalized CV+).
Figure numbering in the manuscript: Fig0_workflow=1, Fig1=2, Fig0b=3, Fig2=4, Fig3=5, Fig4=6, Fig5 (90%)=7, Fig0c=8,
Fig6=9, Fig7=10.

## Revision 2: deployment-specific validation, corrected conformal intervals, cluster-bootstrap inference
| Script | Purpose |
|---|---|
| `conformal.py` | inner-fold schemes (random, composition/system-grouped, leave-one-element-out, forward-chaining), exact CV+ order statistics (Barber et al. 2021), fold-specific normalized CV+, group-weighted CV+ (Dunn et al. 2023) |
| `tests/test_conformal.py` | unit tests (order statistics, coverage on exchangeable synthetic data, weighted quantiles) |
| `bench_v2.py <HV|YS> <shift|ridge|xgbuq>` | P4–P6 with deployment-specific tuning and calibration; tunable ridge for all protocols; all CV+ variants for XGBoost (P1–P3 refits) |
| `v2io.py` | reader for the variable-width prediction files `results/v2/*_pred.csv` |
| `kaggle/tabpfn_v2_cells.py`, `kaggle/hea_tabpfn_v2.ipynb` | TabPFN per-record predictions and deployment-matched CV+ for P4–P6 (GPU) |
| `ingest_tabpfn_v2.py` | decodes the checksummed TabPFN output (`results/remote/tabpfn_v2_*`) |
| `assemble_v2.py` | merges first-run, revision and TabPFN predictions into `results/final/{HV,YS}_{acc,int}.csv` |
| `inference_v2.py` | cluster bootstrap over alloy systems (B = 2000): RMSE CIs, paired differences, Kendall τ, coverage CIs, per-system coverage |
| `analysis_v2.py` | consolidated tables in `results/tables_v2/` |
| `ad_sensitivity_v2.py` | AD sensitivity to k (1–20) and descriptor representation (Table S11) |
| `supplementary_v2.py noise|temporal|external` | repeat scatter (Table S15), temporal overlap (Table S14), external subsets (Table S13) |
| `tuning_scheme_v2.py` | deployment-specific versus system-grouped tuning (Table S16) |
| `run_v2.sh`, `run_v2b.sh` | job queues used for the revision runs |

Order: `bench_v2.py` jobs → `ingest_tabpfn_v2.py` → `assemble_v2.py HV,YS` → `inference_v2.py HV,YS` →
`ad_sensitivity_v2.py HV,YS` → `supplementary_v2.py external` → `tuning_scheme_v2.py` → `analysis_v2.py` →
`screening.py` → `fig_calibration_mechanism.py` → `figures.py` → `graphical_abstract.py`.
The manuscript, SI, cover letter and highlights are generated by `manuscript/make_*.py` (every number in the text is read
from the result tables, and qualitative statements are checked by assertions).
